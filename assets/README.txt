Drop your image files here, named exactly like this, and run "node build.js".
The build then uses your local copy instead of the old Trickle-hosted link:

  logo.png      site logo shown on login / chat / dashboards
  favicon.png   browser tab icon
  crdb.png      CRDB bank logo
  founder.jpg   founder photo
  share.jpg     link-preview image (WhatsApp / social sharing)

Missing files are simply skipped (the old link stays).

airtel.png  - Airtel logo shown in the PAY popup (if missing, the word "airtel" in red is shown instead)
